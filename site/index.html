What Cursor costs — know before the limit runs out

Cursor Cost Tracker is a VS Code / Cursor extension with five jobs.

  • Status bar — Current, Today, and recent queries. Green on pace; red on a spike (!).
  • Guards — Burn Rate toasts and a blocking critical alert. Neither stops Cursor.
  • Monthly forecast — used, forecast, and ideal, plus when limits run out.
  • Optimize — a ready prompt for the last red query. Never reads the chat.
  • Coding stats — landed / AI = % effectiveness, plus All on Cursor by project.

Why this extension

Why Cursor Cost Tracker?

Cursor’s dashboard shows totals on the website — not how much of the month or day is left, when limits run out, which query spiked, or a local way to shrink the next expensive turn.

This extension keeps those numbers next to Git and Problems, with a monthly forecast and Optimize savings in .ai/optimize-savings.md — no chat upload, no third-party analytics.

Inside the editor

It works before you change a setting.

Current and Today show up on the status bar as soon as you install. Click either for Statistics. Click a query chip for the list. Charts, Optimize, Support, and Settings stay one panel away.

Status bar

Spend stays visible while you type

Current is the billing cycle. Today is the daily pace. Up to ten recent queries sit beside them. Anything at or above Warn at (default 1M tokens) gets a red !.

Statistics

The month, the burn, the sample

Meters for Current and Today, live burn rate when Guard is on, coding stats when enabled, plus the Last N totals.

Last N

Every recent query, newest first

Time, model, cost, tokens, input / output, kind. Spike rows highlight TOKENS. Export CSV from the toolbar.

Optimize

A prompt for the last red query

Quick, Balanced, or Deep. Run pastes into the open Agent chat — you press Start. The extension never reads the transcript.

  • Critical alert. One dialog, only at 10M tokens or $5. Separate from the ! on the bar. Cursor keeps running.
  • Eleven languages. English by default. Polish, Chinese, Japanese, and more switch the panel, status bar, and toasts immediately.

Before you install

Does Optimize read the chat?

No. The prompt is built from usage metadata for the last red query. The transcript stays in Cursor. A projected save shows up only after the agent writes .ai/optimize-savings.md.

Pro, or a team plan?

Pro shows included percent for Cursor Models and Other Models. Team, Business, and Enterprise show dollars and one Spend series. The same chart draws used, forecast, and ideal either way.

What do I paste?

Nothing. The extension reuses the Cursor session already on this computer. There is no API key and no second login.

What if Cursor changes the usage API?

The extension is unofficial. If that API moves, the numbers can stall until a release catches up. The token never goes to the panel or the logs.

Privacy

Your session stays on this machine.

No pasted access token. No proxy. Usage calls go straight to cursor.com using the Cursor session that already exists locally. The panel and logs never show the token.

Optimize builds a prompt from usage metadata only. Projected savings appear when the agent writes .ai/optimize-savings.md in the project — not from a transcript scrape.
