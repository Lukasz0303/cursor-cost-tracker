## 2. Locked product rules

These apply to every feature. A feature plan may not weaken them.

| Rule | Meaning |
|------|---------|
| **G5 — one blocking modal** | Only the last-query **critical alert** (default 10M tokens or $5) may use `{ modal: true }`. Runaway and Daily Guard use `showWarningMessage` **without** `modal`, plus status-bar `warnColor` and a Statistics banner. |
| **Cannot stop Cursor** | The extension cannot halt Composer / Agent. Copy must say the warning does not stop spend. |
| **No transcripts** | Usage events have no conversation id (timestamp, model, kind, tokens, cost only). No chat body, no workspace LLM scan, no auto-fix. Optimize stays metadata prompts. |
| **No 7th tab** | Keep Last N / Statistics / Charts / Optimize / Support / Settings. New UI folds into those surfaces. |
| **No secrets in webview** | Payload stays formatted rows + stats. Never cookie, access token, or email beyond what the PRD already allows. |
| **Show warnings** | When `cursorCost.showSpikeWarning` is off: no `!` and no green/red on the bar or table. Feature-specific toasts/banners follow each plan. |
| **Settings apply rules** | New numeric settings save on Apply / Enter / blur — not while typing (same as Show last / Critical alert). |
| **Zero-setup defaults** | New caps and detectors must not surprise a fresh install. Daily cap default is **off** (`0`). Detectors that only warn may default **on**. |
| **Language** | English UI strings, settings descriptions, commits, `.ai`, and tests. |
| **Versioning** | Each feature is a **MINOR** (`package.json`). PATCH only for algorithm / copy fixes after that MINOR. Git tags `vX.Y.Z`. |

## 3. Surfaces (shared)

```
UsageQuery[] ──► runaway detect ──► non-modal toast + bar ! + Last N badge + Statistics banner
            ├──► daily cap vs todayUsedUsd ──► Today chip denominator + toast + Statistics meter
            ├──► session cluster ──► efficiency score card (Statistics)
            ├──► token-band × model ──► advisor card (Statistics)
            └──► fingerprint stamp (workspace + git) ──► by-project bars + Last N filter + CSV
```

| Surface | Role |
|---------|------|
| Status bar | Today chip uses the **user** daily cap when set (1.3). Runaway tints query chips / `!` when warnings are on (1.2). |
| Last N table | Keep TIME, MODEL, COST, TOKENS, INPUT / OUTPUT, KIND. Runaway = badge / `runaway` flag (1.2). Attribution = **filter chips**, not a 7th column (1.6). |
| Statistics | Banners + new cards (score, advisor, by-project). Keep Current/Today glossary, MTD forecast, by-model / by-kind. |
| Optimize | Optional extra **finding** from metadata (runaway / advisor). No new prompt depth. |
| Settings | New `cursorCost.*` fieldsets (same ghost/pill cards as Critical alert / Monthly budget). |
| Charts | No required change. 1.6 may reuse period mix later; not in the 1.6 MVP. |

## 4. Implementation order

Implement **one MINOR at a time**. Do not land 1.3–1.6 code in the 1.2 PR.

1. **1.2 Runaway** — no dependency on later features. Optional burn-$ signal uses a local constant / setting default **off**, not the 1.3 cap.
2. **1.3 Daily Guard** — independent of 1.2. After both exist, 1.2 may *optionally* treat “window spend ≥ remaining daily cap” as a burn signal in a follow-up PATCH — not required to ship 1.3.
3. **1.4 Efficiency score** — uses Last N + spike threshold; independent of 1.2/1.3.
4. **1.5 Model advisor** — extends spend-by-model; independent, but after 1.4 so Statistics card layout is stable.
5. **1.6 Attribution** — independent data path (`globalState` map). Last because it is the Team-facing foundation and touches CSV / filters.

v1.1 **Ignore** (`IgnoreStore`) stays leftover. Do not block 1.2 on Ignore.
